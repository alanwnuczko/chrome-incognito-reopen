# chrome-incognito-reopen

Chrome extension that reopens the current tab in an incognito window via a keyboard shortcut.

## Install

1. Download the latest `.zip` from [Releases](https://github.com/alanwnuczko/chrome-incognito-reopen/releases) and extract it
2. Go to `chrome://extensions`
3. Enable "Developer mode" (top right)
4. Click "Load unpacked" and select the extracted folder
5. Go to `chrome://extensions/shortcuts`

>[!NOTE]
>To change the default shortcut, find "Reopen Tab in Incognito" and confirm/change the shortcut (default is `Ctrl+Shift+Y` / `Cmd+Shift+Y` on Mac)

>[!IMPORTANT]
>On the extension's card in `chrome://extensions`, click "Details" and toggle "Allow in Incognito" if you want the shortcut to also work while you're already in an incognito window
